# Released numerical results

This release contains numerical outputs for the v0.3 manuscript, not trained
weights, embeddings, raw molecular data, or per-molecule predictions. No GPU,
Slurm job, dataset download, or machine-learning dependency is needed to inspect
the results or run the lightweight reproduction:

```bash
python scripts/reproduce_results.py --output results/reproduced
python -m unittest discover -s tests -p 'test_released_results.py'
```

Execution path: **[CPU → local, no sbatch]**. Python's standard library is enough.
The first command writes six CSV tables and `reproduction_report.json`. It checks
the recomputed values against the released numerical records; disagreement
raises an error. Generated files can be placed outside the repository by changing
`--output`.

## What is recomputed, and what is retained

The command recomputes all 4,170 descriptive means/SDs from 33,768 pooled
representation-seed/head/task metric cells. It independently reconstructs the
original primary-scope fit metrics from 5,952 fold-level MAE/RMSE records. It then
recalculates all 121 requested paired point estimates: the original three
aggregate primary comparisons, 70 completed task/adaptation comparisons,
24 structural comparisons, and 24 same-record property-bridge comparisons.

**Confidence intervals are retained numerical outputs, not rerun bootstrap
estimates.** The command reads the saved, unrounded endpoints and converts them
for display. The original 10,000-resample hierarchical analyses require paired
prediction rows and their family, structure-group, row, or anchor nesting.
Those inputs are not included. Resampling the released fit metrics would not
reproduce that analysis, so this command does not do it. Saved p-values and
Holm adjustments are also retained, not re-estimated.

The source implementation of the full analyses remains in
`src/polyfid/analysis/statistics.py`, `posttraining_bootstrap.py`, and
`draft_closure_statistics.py`. Re-running those analyses requires generating the
underlying prediction/relation outputs through the full experimental workflow.
This lightweight release is sufficient for numerical aggregation and table
reproduction, not end-to-end experimental reproduction.

The geometry contrast is `A_eqs - A_gcl`. Error/stability contrasts use
`log(candidate / baseline)`. Internal name `verified_relations` identifies the
`A_eqs` versus `A_gcl` comparison; it does not assert a general physical-equivalence
guarantee. The fixed molecular reference `C` has representation seed zero.

## Aggregation conventions

Fold MAE is pooled by instance count:
`sum(n_fold * MAE_fold) / sum(n_fold)`. Fold RMSE is pooled as
`sqrt(sum(n_fold * RMSE_fold**2) / sum(n_fold))`, not as an average of fold RMSEs.
Counts denote held-out prediction instances and need not represent unique
structures across folds.

Descriptive errors average heads within each representation and then average
representations equally. Their SD is over the five representation means, not
15 independent pretraining repeats. A fixed representation instead reports
downstream-fit variability; deterministic ridge/nearest-neighbor fits have no
seed SD. Low-data subsamples remain separate in the complete 4,170-row matrix.
The command does not replace those entries with a different low-data average.

Paired error effects take a log ratio within each matched fit before averaging
task/head cells and representations. Dividing two descriptive means is a
different statistic. The original 12-task scope uses family OOD and MAE for
EA/IP, the official group-disjoint protocol for PE-I, and group OOD/RMSE for the
other tasks. It excludes molecular retention, metadata-augmented PE-I, and
external models. Only the original three aggregate primary comparisons belong
to the primary Holm family; the 70 completed comparisons and the geometry and
bridge intervals do not expand it.

Display conversion is `100 * (exp(log_ratio) - 1)` for error/stability changes.
Geometry recall and accuracy differences are multiplied by 100 for percentage
points; cosine, margin and MRR remain differences. The original-scale estimates
and interval endpoints are preserved alongside the converted values.

## Provenance and scope

The retained result snapshot comes from the manuscript archive
`paper/revisions/v0.3_p4/reproducibility/code/github_release/results/`. Additional
per-repetition inputs come from the corresponding completed project statistics:
`results/statistics/completed_experiments/tables/pooled_seed_metrics.csv`,
`formal_frozen_probes/task_metrics.csv`, the geometry/bridge metric and scope
tables, and the mechanism-control/token-efficiency seed tables. The primary fold
table is an exact row subset of `task_metrics.csv`, selected by the protocols in
the original `primary_aggregate.csv`, test split, full labels, subsample zero,
and `valid` input view. Numeric source values were not edited.

The complete descriptive companion comes from the v0.3 archive's
`reproducibility/sources/si_complete_descriptive_matrix_data.csv`. Its numeric
values agree with the completed model summary within floating-point precision.
Archived path fields are project-relative provenance labels; they are not a
promise that excluded data or scheduler manifests ship in this repository.

The same-record bridge is a seven-task secondary analysis on 4,765 common
task-records, not the 12-task primary comparison. Geometry and predictive
stability results must not be substituted for property-error improvements.
Supporting three-seed mechanism controls remain distinct from the five-seed
main comparison. All original source results were left untouched when preparing
this publication copy.
